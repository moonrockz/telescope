# Telescope

Telescope is a MoonBit and Rabbita toolkit for static project documentation.
The `moonrockz/telescope` library supplies configuration, content, views and
site planning, with reusable native IO in `moonrockz/telescope/host`. The matching
native `telescope` CLI builds, checks, previews and assembles consumer-supplied
version trees. Consumers own their domain engines and reviewed content.

Version **0.2.0 is released** as `moonrockz/telescope@0.2.0` on Mooncakes and
matching [native CLI archives](https://github.com/moonrockz/telescope/releases/tag/v0.2.0).
It adds Smithy-aligned themes, gallery preview cards, family and text filters,
and accessible Preview/Source inspection with copying and downloads.
See [default presentation](docs/presentation.md).

Clean public installs pass on Linux x64 and macOS arm64 without workspace
overrides. See [installation and compatibility](docs/release/0.2.0.md).

```sh
mise trust
mise install
mise run format
mise run check:setup
mise run check
mise run package
mise run test:consumer -- --prepared
```

The package task builds a relocatable native CLI with embedded generic CSS and
browser islands, creates its archive and SHA-256 download checksum, and runs
`moon package` for the library. It does not publish.

```sh
_build/telescope/telescope --version
_build/telescope/telescope build --config site/site.json --out _site
_build/telescope/telescope check --config site/site.json --out _site --format json
_build/telescope/telescope serve --config site/site.json --out _site --port 4173
_build/telescope/telescope assemble --manifest site/versions.json --out _site
```

See [CONTRIBUTING.md](CONTRIBUTING.md), [CLI and configuration](docs/cli.md),
[installation and qualification](docs/release/install.md), and the
[release procedure](docs/release/README.md). The library's
[package README](pkgs/telescope/README.md) documents its public namespaces.

Reviewed HTML is trusted repository content, not sanitized upload input.
Complete HTML documents retain their own heads. Development templates, planning
artifacts and build output are excluded from discovery by default. Gallery
inputs are checked artifacts generated by the consumer, without per-file hashes.
