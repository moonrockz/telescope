# Browser API fixture

Generated from modules/sample with MoonBit 0.10.18+6c83a7f62 using moon doc.
MoonBit 0.10.20+65efd5b93 writes the same format; it links `Json` to
`moonbitlang/core/json` instead of `moonbitlang/core/builtin`. These are compiler-generated module_index and package_data inputs,
not hand-authored API output. The global browser setup feeds them to the real
host and CLI to test the shared presentation on an actual API page.
