# Telescope 0.1.0

The library is published as `moonrockz/telescope@0.1.0` on
[Mooncakes](https://mooncakes.io/docs/moonrockz/telescope).
The [matching CLI release](https://github.com/moonrockz/telescope/releases/tag/v0.1.0)
was published by [Actions run 40520332727](https://github.com/moonrockz/telescope/actions/runs/40520332727)
from source `f119b0621d4a6dfe02a5e84615027a133e7f460f`, after owner-approved
[PR 4](https://github.com/moonrockz/telescope/pull/4) merged.

## Install

Pin the library in a native consumer's `moon.mod`:

```moonbit
import {
  "moonrockz/telescope@0.1.0",
}
preferred_target = "native"
```

Run `moon update` to initialize a new public registry, then build the consumer
with MoonBit `0.10.17+093cb8f9c`. Import the needed public packages in `moon.pkg`,
such as `moonrockz/telescope/host` and `moonrockz/telescope/extensions`.

Download the archive and its `.sha256` companion for your platform:

| Platform | Archive | SHA-256 |
| --- | --- | --- |
| Linux x64 | [telescope-0.1.0-linux-x64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.1.0/telescope-0.1.0-linux-x64.tar.gz) | `b3d50d78b3501201b22a6c4edb65586eae7f6a479400e8b39ad246091479ae4a` |
| macOS arm64 | [telescope-0.1.0-macos-arm64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.1.0/telescope-0.1.0-macos-arm64.tar.gz) | `ccd64087bb288bbe741de5d49091ca654eebba8cadcad140f5cd6b5c289ff320` |

For example, on macOS arm64:

```sh
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.1.0/telescope-0.1.0-macos-arm64.tar.gz
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.1.0/telescope-0.1.0-macos-arm64.tar.gz.sha256
shasum -a 256 -c telescope-0.1.0-macos-arm64.tar.gz.sha256
tar -xzf telescope-0.1.0-macos-arm64.tar.gz
./telescope-0.1.0-macos-arm64/telescope --version
```

The last command prints `0.1.0`. Extracted CLI binaries contain CSS and browser
islands and need no Telescope checkout or MoonBit compiler. A compiled consumer
with custom providers needs the pinned MoonBit toolchain. Other native platforms
are not qualified by this release.

## Compatibility

Library and CLI versions are both `0.1.0`. Configuration, extension-adapter and
gallery-manifest contracts are version `1`. MoonBit API ingestion is qualified
against compiler `0.10.17+093cb8f9c`. Pure model/content/gallery/extensions packages
check on wasm, wasm-gc, JS and native; CommonMark, Rabbita views and filesystem
hosting use native packages. Browser islands use JS.

Use the released [public library API](https://github.com/moonrockz/telescope/blob/f119b0621d4a6dfe02a5e84615027a133e7f460f/pkgs/telescope/README.md),
[native host](https://github.com/moonrockz/telescope/blob/f119b0621d4a6dfe02a5e84615027a133e7f460f/pkgs/telescope/host/README.md),
[provider contract](https://github.com/moonrockz/telescope/blob/f119b0621d4a6dfe02a5e84615027a133e7f460f/pkgs/telescope/extensions/README.md),
[gallery contract](https://github.com/moonrockz/telescope/blob/f119b0621d4a6dfe02a5e84615027a133e7f460f/pkgs/telescope/gallery/README.md) and
[CLI configuration](https://github.com/moonrockz/telescope/blob/f119b0621d4a6dfe02a5e84615027a133e7f460f/docs/cli.md). Consumers compile their own renderer providers
and own gallery artifact generation, release selection and deployment. Telescope
contains no diagram engine and does not fetch historical releases during assembly.

## Published qualification

The release job installed from the actual public registry and GitHub downloads
on Linux x64. The coordinator repeated the same command on macOS arm64:

```sh
mise run test:consumer -- --published 0.1.0
```

Both passed with empty registry homes and no candidate entry, local path or
workspace override. They verified the exact dependency and CLI version, archive
checksum, compiled custom fence provider, deterministic builds and checks at `/`
and `/example/`, failed-build preservation, API generation and preview shutdown.
Retained reports are [Linux](consumer-0.1.0-linux-x64.json) and
[macOS](consumer-0.1.0-macos-arm64.json).

The same release passed 221 native engine tests, two owner-gate tests, two
publisher regressions and the fresh-public-index regression on both platforms,
plus 38 Linux browser checks. The separate actual-diagrams source fixture
preserved 77 routes, 5,376 anchors and 40 gallery artifact bytes across supplied
version trees. That source fixture complements the real published-consumer
qualification; diagrams adoption has its own integration checks.

## Known integration gaps

The real diagrams consumer found that 0.1.0 omits the gallery primary header
link, family grouping and explicit SVG download links. Supplied-tree assembly
also omits the pre-existing latest-page canonical links. These gaps are fixed in
the [published and qualified 0.1.1 patch](0.1.1.md). Consumers that
need these fixes should pin that released version. Diagrams' own integration
verification is tracked separately.
