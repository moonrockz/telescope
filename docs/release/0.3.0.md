# Telescope 0.3.0

The library is published as `moonrockz/telescope@0.3.0` on
[Mooncakes](https://mooncakes.io/docs/moonrockz/telescope).
The [matching CLI release](https://github.com/moonrockz/telescope/releases/tag/v0.3.0)
was published by owner-approved
[Actions run 40637807149](https://github.com/moonrockz/telescope/actions/runs/40637807149)
from exact source `6afd8622e81a1778467fc55a8242d2071d3c39d0`, after
[PR 11](https://github.com/moonrockz/telescope/pull/11) merged. The release tag
points to that same commit. Separate owner approval of this exact version and
commit preceded the publication dispatch.

This release adds optional TOML tutorial manifests, stable course/lesson routes,
static reading and tested source includes, consumer-owned local execution,
case/evidence checking, comparison and stepping. The reusable editor and public
Formatter belong to `moonrockz/telescope/editor` and require no tutorial setup.
Its optional rich adapter ships MoonBit highlighting selected by `moonbit` or
`mbt`, without a compiler or formatter requirement.

## Install

Pin the library in a native consumer's `moon.mod`:

```moonbit
import {
  "moonrockz/telescope@0.3.0",
}
preferred_target = "native"
```

Run `moon update` with MoonBit `0.10.17+093cb8f9c`. Import the public packages
needed in `moon.pkg`, such as `moonrockz/telescope/host` or
`moonrockz/telescope/editor`.

Download the archive and its `.sha256` companion for your platform:

| Platform | Archive | SHA-256 |
| --- | --- | --- |
| Linux x64 | [telescope-0.3.0-linux-x64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.3.0/telescope-0.3.0-linux-x64.tar.gz) | `bd4c1d8cda1d677c97bdaf65f7c89560d7d4176419d483290291c1c36da24bf9` |
| macOS arm64 | [telescope-0.3.0-macos-arm64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.3.0/telescope-0.3.0-macos-arm64.tar.gz) | `52bf784ded3a463a07cd5614e36de99a6894b8b88d01f2a23469fd5bccad02c7` |

For example, on macOS arm64:

```sh
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.3.0/telescope-0.3.0-macos-arm64.tar.gz
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.3.0/telescope-0.3.0-macos-arm64.tar.gz.sha256
shasum -a 256 -c telescope-0.3.0-macos-arm64.tar.gz.sha256
tar -xzf telescope-0.3.0-macos-arm64.tar.gz
./telescope-0.3.0-macos-arm64/telescope --version
```

The last command prints `0.3.0`. Native binaries embed shared CSS and browser
assets and need no checkout or compiler. Custom compiled providers need the
pinned toolchain. Other native platforms are not qualified by this release.
Archives retain third-party licenses, including the TOML parser and optional
editor dependencies.

## Compatibility

Existing site JSON, version-one extension registries and host calls remain
source compatible with 0.2.1. Tutorial inputs are optional and separately decoded.
Authored tutorials use TOML schema version 1; runtime envelopes, expectations and
reports use JSON. Provider and formatter protocols start at contract version 1.
Consumers ship prebuilt assets and compile their own evaluator/formatter
implementations. Builds validate/render without executing an engine. Case
checking is a separate host API and consumer-driver operation.

See [authoring](../tutorials.md), [general editor](../editor.md),
[provider contracts](../tutorial-contracts.md) and the
[verification/parity matrix](../tutorial-verification.md).

portable/native checks, 282 native tests, two release-gate tests, publisher and
fresh-public-index regressions, packaging and prepared consumers. Native/worker
wire parity and 18 JS tests passed; Linux's full Chromium suite passed 108
scenarios. The owner-approved publication job promoted those qualified archives.

x64. An independent macOS arm64 run passed the same command:


CLI archive with SHA-256 verification. Neither seeded a candidate package nor
