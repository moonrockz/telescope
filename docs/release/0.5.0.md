# Telescope 0.5.0

The library is published as `moonrockz/telescope@0.5.0` on
[Mooncakes](https://mooncakes.io/docs/moonrockz/telescope), with a
[matching CLI release](https://github.com/moonrockz/telescope/releases/tag/v0.5.0). Owner-approved
[Actions run 40895904607](https://github.com/moonrockz/telescope/actions/runs/40895904607) published exact source
`4116b2d51da5ff8999ca8437e4aa0a973e7babdf` after [repair PR 19](https://github.com/moonrockz/telescope/pull/19).
The tag points to that commit. The live owner/admin gate verified the exact
commit, version and merged PR before publication.

## Behavior and compatibility


Manifest version 1 and the public plan signature stay compatible. Every declared
source retains its filename, MIME type and byte-preserving artifact download.
The index and detail page use the same exact escaped source sections. Scripting
adds independent keyboard tabs and copy feedback; static reading shows both
sections. Planned examples retain their placeholders. Mounted viewers retain
zoom/pan while tabs, filters and hidden viewport resize change visibility.
Existing family fragments, detail links, fullscreen, raster export and active
version-tree artifact URLs remain available.

The shared gallery CSS classes apply in both contexts. The optional
`--gallery-card-source-height` property changes the default `20rem` scroll height.
Consumers continue to own original syntax and declare source honestly; no source
is derived from SVG and no domain renderer is added.

With scripts, a labeled Source file selector chooses among multiple declared
files and retains its selection across tabs and filtering. Without scripts,
all files remain visible. `.gallery-source-select` styles the selector.

The library API and manifest version 1 remain compatible with 0.4.0. The
supported compiler remains MoonBit `0.10.17+093cb8f9c`.

## Install

Pin the public library in a native consumer:

```moonbit
import {
  "moonrockz/telescope@0.5.0",
}
preferred_target = "native"
```

Run `moon update` and import the required public packages, such as
`moonrockz/telescope/host`, in `moon.pkg`. Download the native archive and its
`.sha256` companion for the qualified platform:

| Platform | Archive | SHA-256 |
| --- | --- | --- |
| linux-x64 | [telescope-0.5.0-linux-x64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.5.0/telescope-0.5.0-linux-x64.tar.gz) | `ed25fe34173e7032035708bcfdaec06500bacfa9366916851b75ca675fb8ed6a` |
| macos-arm64 | [telescope-0.5.0-macos-arm64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.5.0/telescope-0.5.0-macos-arm64.tar.gz) | `8af13f0e2727eac93e5020f11c9a52400087cef9900d746e4c581b4337a2f153` |

```sh
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.5.0/telescope-0.5.0-macos-arm64.tar.gz
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.5.0/telescope-0.5.0-macos-arm64.tar.gz.sha256
shasum -a 256 -c telescope-0.5.0-macos-arm64.tar.gz.sha256
tar -xzf telescope-0.5.0-macos-arm64.tar.gz
./telescope-0.5.0-macos-arm64/telescope --version
```

The last command prints `0.5.0`. The CLI embeds its shared CSS and browser
islands and requires no checkout or compiler. Compiled library consumers need
the pinned toolchain. Other native platforms are not qualified.

## First publication attempt and repair


Owner-approved [run 40869479241](https://github.com/moonrockz/telescope/actions/runs/40869479241)
targeted source `d366bfe26f87d607ca7b3652b5c035b3b295902e` for publication.
Both platform jobs stopped in setup validation before publication. Two task
scripts pinned the root async import to 0.22.5 but left package imports
unversioned. A fresh public index resolved those imports to 0.22.6, and the
compiler rejected the conflicting versions. No publication step ran.

The repair pins five async package imports to 0.22.5. The original scripts
reproduce the failure against a fresh public index; repaired scripts compile
against that same index. The owner then separately approved the repaired merge
SHA and 0.5.0 before the successful dispatch above. No failed candidate artifact
was substituted for the actual published distributions.
