# 0.5.0 candidate

This candidate adds independent Preview/Source tabs on implemented gallery index
cards. It is not published and must not be adopted as a downstream dependency.
The published 0.4.0 library and CLI remain available.

## Behavior and compatibility

Manifest version 1 and the public plan signature stay compatible. Every declared
source retains its filename, MIME type and byte-preserving artifact download.
The index and detail page use the same exact escaped source sections. Scripting
adds independent keyboard tabs and copy feedback; static reading shows both
sections. Planned examples retain their placeholders. Mounted viewers retain
zoom/pan while tabs, filters and hidden viewport resize change visibility.
Existing family fragments, detail links, fullscreen, raster export and active
version-tree artifact URLs remain available.

The shared gallery CSS classes apply in both contexts. The optional
`--gallery-card-source-height` property changes the default `20rem` scroll height.
Consumers continue to own original syntax and declare source honestly; no source
is derived from SVG and no domain renderer is added.

## Candidate qualification

The isolated macOS arm64 checkout first qualifies baseline 0.4.0 with a packaged
library and CLI in a fresh consumer. Candidate checks run pinned format/setup,
strict engine checks across four MoonBit targets, native tests, actual Chromium
browser tests and independent packaged library/CLI consumers. Browser checks
cover root/nested deployment, root/next/latest/historical trees, both themes,
360/768/1440 widths, no scripts, exact source, multiple files, clipboard denial,
unique IDs, mounted state, resize while hidden, filtering and viewer actions.
Local macOS arm64 qualification passed 285 native tests, two release-gate tests,
124 Chromium tests, fresh packaged library/CLI consumers, public-index bootstrap
and two publisher-environment tests. The four portable targets passed strict
checks. Linux x64 candidate CI remains required before publication.

Local logs and machine-readable receipts are retained under `_build/evidence/`
and `_build/browser/`; the worker handoff records the exact prepared commit and
archive checksums. Candidate cache seeding is explicit and does not prove public
installation. Publisher-environment qualification uses no credential.

## Publication gate

The coordinator owns PRs and publication. Before publication, obtain owner approval naming the exact merged source SHA
and 0.5.0.
Both Linux x64 and macOS arm64 candidate jobs must pass on that source. Publish
only through the approved GitHub Actions workflow, with its merged release PR,
exact approved merge SHA and version. No workstation publication is authorized.

After publication, verify the actual Mooncakes coordinate and matching CLI
archives, checksum downloads and fresh public consumers on both platforms.
Record the owner/admin dispatch, PR, merge SHA and public-install evidence in the
final evidence PR. Keep the release story open and the OpenSpec change active
until that evidence exists and its final PR merges.

With scripts, a labeled Source file selector chooses among multiple declared
files and retains its selection across tabs and filtering. Without scripts,
all files remain visible. `.gallery-source-select` styles the selector.
