# Telescope 0.2.1

The library is published as `moonrockz/telescope@0.2.1` on
[Mooncakes](https://mooncakes.io/docs/moonrockz/telescope).
The [matching CLI release](https://github.com/moonrockz/telescope/releases/tag/v0.2.1)
was published by owner-approved
[Actions run 40594390130](https://github.com/moonrockz/telescope/actions/runs/40594390130)
from source `1f84c6c8de780ea9322db6eef14c10395a4670f9`, after
[PR 8](https://github.com/moonrockz/telescope/pull/8) merged.

This patch aligns Reset filters with the gallery textbox and uses the shared
indigo accent fill with contrasting text in both themes. The empty-state reset
uses the same styling, and narrow toolbars retain their wrapping.

## Install

Pin the library in a native consumer's `moon.mod`:

```moonbit
import {
  "moonrockz/telescope@0.2.1",
}
preferred_target = "native"
```

Run `moon update` with MoonBit `0.10.17+093cb8f9c`. Import the public packages
needed in `moon.pkg`, such as `moonrockz/telescope/host`.

Download the archive and its `.sha256` companion for your platform:

| Platform | Archive | SHA-256 |
| --- | --- | --- |
| Linux x64 | [telescope-0.2.1-linux-x64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.2.1/telescope-0.2.1-linux-x64.tar.gz) | `452fda1f4300f65d2b56e80a526fdc48b4ee027ec0c02f44464566b387cde145` |
| macOS arm64 | [telescope-0.2.1-macos-arm64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.2.1/telescope-0.2.1-macos-arm64.tar.gz) | `9bac662547f7e52867ad57ef914b9518161952337392e5ed8083623a1117ba4e` |

For example, on macOS arm64:

```sh
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.2.1/telescope-0.2.1-macos-arm64.tar.gz
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.2.1/telescope-0.2.1-macos-arm64.tar.gz.sha256
shasum -a 256 -c telescope-0.2.1-macos-arm64.tar.gz.sha256
tar -xzf telescope-0.2.1-macos-arm64.tar.gz
./telescope-0.2.1-macos-arm64/telescope --version
```

The last command prints `0.2.1`. Native binaries embed the shared CSS and browser
islands and need no checkout or compiler. Custom compiled providers need the
pinned toolchain. Other native platforms are not qualified by this release.

gallery-manifest contracts remain version 1. Public APIs, gallery routes and
artifact bytes remain compatible with [0.2.0](0.2.0.md). Existing two-argument
pure gallery planner calls remain supported. Pure packages check on wasm,
wasm-gc, JS and native; the host and CommonMark/Rabbita adapters use native.
