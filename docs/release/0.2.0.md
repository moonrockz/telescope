# Telescope 0.2.0 candidate

Status: local candidate qualification passed. Publication is not approved.
The current published version remains 0.1.1.

The candidate changes the shared palette to Smithy indigo and cool neutral colors
and adds visual gallery browsing and Preview/Source inspection. See
[default presentation](../presentation.md) and the gallery package documentation.

The manifest remains version 1. Existing two-argument pure gallery planner calls
remain supported; source text is an optional explicit input. The host reads
verified declared sources for static source inspection. Sources and preview
artifacts retain their bytes, and existing routes and family anchors stay valid.

The library and CLI must both be 0.2.0. Before publication, qualify packaged
consumers on Linux x64 and macOS arm64 and browser behavior on the candidate.
Record the exact PR head and qualification run here after checks finish.
Owner approval must name the release commit/version. Publish through the existing
Actions workflow; never publish from a workstation.

After publication, replace this candidate status with actual release URLs, archive
checksums and independent public-consumer reports. Send that evidence to the
diagrams coordinator before changing any downstream published dependency pins.

## Local candidate qualification

- `mise run format`, `mise run check:setup` and strict OpenSpec validation passed.
- `mise run check` passed 232 native tests, two release-gate tests and pure-package
  compiler checks across wasm, wasm-gc, JS and native.
- Pure gallery tests passed 12 cases on each of those four targets.
- `mise run package` prepared the matching library and macOS arm64 CLI archive.
- The publisher environment passed two tests without a credential.
- `mise run test:consumer -- --prepared` passed in a clean consumer with an
  explicitly seeded candidate cache, no workspace override, both base paths,
  static source inspection and unchanged artifact bytes. This is not publication.
- `mise run test:browser` passed all 56 cases, including root/nested bases, actual
  compiler-metadata API pages, theme combinations, contrast, gallery filtering,
  keyboard tabs, multiple sources, copy failure and no-script fallback.
- A separate copied-source diagrams compatibility proof retained 77 routes,
  5,376 anchors and 40 artifact files. The expanded diagrams browser suite passed
  against that candidate preview. This is not a released dependency adoption.
- Building again while the candidate preview remained running passed after
  switching CLI replacement to an atomic rename. The new CLI reports 0.2.0 and
  the existing preview keeps answering successfully.

Linux x64 and macOS arm64 CI must pass on the actual release PR head. Public
installation evidence remains pending publication approval and Actions execution.

The PR review found source URLs could change when a version tree was assembled.
A failing browser regression reproduced that mismatch at both deployment bases.
Source-only slash character references now preserve exact displayed and copied
text across root, next, latest and both minor trees while normal links rebase.
All 56 browser cases pass with that regression. Phone-width family links wrap
above the previews; the actual twelve-example consumer checks that the first
preview remains in the narrow viewport.
