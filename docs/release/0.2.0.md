# Telescope 0.2.0

The library is published as `moonrockz/telescope@0.2.0` on
[Mooncakes](https://mooncakes.io/docs/moonrockz/telescope).
The [matching CLI release](https://github.com/moonrockz/telescope/releases/tag/v0.2.0)
was published by owner-approved
[Actions run 40573188390](https://github.com/moonrockz/telescope/actions/runs/40573188390)
from source `597f50ab27ffc116d50b48c7a402a250ade856b2`, after
[PR 7](https://github.com/moonrockz/telescope/pull/7) merged.

The release uses Smithy's indigo and cool neutral defaults and adds visual
gallery browsing and Preview/Source inspection. See
[default presentation](../presentation.md).

## Install

Pin the library in a native consumer's `moon.mod`:

```moonbit
import {
  "moonrockz/telescope@0.2.0",
}
preferred_target = "native"
```

Run `moon update` and use MoonBit `0.10.17+093cb8f9c`. Import the needed public
packages in `moon.pkg`, such as `moonrockz/telescope/host` and
`moonrockz/telescope/extensions`.

Download the archive and its `.sha256` companion for your platform:

| Platform | Archive | SHA-256 |
| --- | --- | --- |
| Linux x64 | [telescope-0.2.0-linux-x64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.2.0/telescope-0.2.0-linux-x64.tar.gz) | `1000e96a2f0b8572be8dc896c7e825e0d83a9f7303263f362a4aefdf02604b97` |
| macOS arm64 | [telescope-0.2.0-macos-arm64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.2.0/telescope-0.2.0-macos-arm64.tar.gz) | `db9600b57572af656d0bf9ee129546ddc485e8964b205c66171f8187f02314a7` |

For example, on macOS arm64:

```sh
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.2.0/telescope-0.2.0-macos-arm64.tar.gz
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.2.0/telescope-0.2.0-macos-arm64.tar.gz.sha256
shasum -a 256 -c telescope-0.2.0-macos-arm64.tar.gz.sha256
tar -xzf telescope-0.2.0-macos-arm64.tar.gz
./telescope-0.2.0-macos-arm64/telescope --version
```

The last command prints `0.2.0`. Extracted CLI binaries contain CSS and browser
islands and need no checkout or MoonBit compiler. Custom compiled providers need
the pinned compiler. Other native platforms are not qualified by this release.

## Compatibility

Library and CLI versions are both `0.2.0`. Configuration, extension-adapter and
gallery-manifest contracts remain version `1`. Existing two-argument pure gallery
planner calls remain supported; source text is an optional explicit input.
The host reads verified declared sources for static inspection. Sources and
preview artifacts retain their bytes, routes and family anchors.

Pure model/content/gallery/extensions packages check on wasm, wasm-gc, JS and
native. CommonMark, Rabbita views and filesystem hosting use native packages.
Browser islands use JS. API ingestion is qualified against the pinned compiler.

Use the released [public API](https://github.com/moonrockz/telescope/blob/597f50ab27ffc116d50b48c7a402a250ade856b2/pkgs/telescope/README.md),
[native host](https://github.com/moonrockz/telescope/blob/597f50ab27ffc116d50b48c7a402a250ade856b2/pkgs/telescope/host/README.md),
[provider contract](https://github.com/moonrockz/telescope/blob/597f50ab27ffc116d50b48c7a402a250ade856b2/pkgs/telescope/extensions/README.md),
[gallery contract](https://github.com/moonrockz/telescope/blob/597f50ab27ffc116d50b48c7a402a250ade856b2/pkgs/telescope/gallery/README.md) and
[CLI configuration](https://github.com/moonrockz/telescope/blob/597f50ab27ffc116d50b48c7a402a250ade856b2/docs/cli.md).
Consumers own renderer providers, artifacts, release selection and deployment.
Telescope contains no diagram engine and does not fetch historical releases.
