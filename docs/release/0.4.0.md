# Telescope 0.4.0

The library is published as `moonrockz/telescope@0.4.0` on
[Mooncakes](https://mooncakes.io/docs/moonrockz/telescope).
The [matching CLI release](https://github.com/moonrockz/telescope/releases/tag/v0.4.0) was published by owner-approved
[Actions run 40767534086](https://github.com/moonrockz/telescope/actions/runs/40767534086) from exact source `8ab416c7f6e1fc1973f5a4b0caac628978f0895f`,
after [PR 16](https://github.com/moonrockz/telescope/pull/16) merged.
The release tag points to that same commit. The manual owner/admin gate verified
the approved commit, version and merged release PR before the credential-dependent
dry run and publication.

## Included behavior and migration

[PR 15](https://github.com/moonrockz/telescope/pull/15) added gallery fullscreen,
bounded zoom, pan and Fit controls, stable viewer styling and theme hooks,
optional header/favicon assets, and a consumer-owned local PNG/JPEG adapter
contract. The release also fixes modal fullscreen scroll restoration near the
page bottom. Source and static SVG bytes remain unchanged. Telescope consumers
supply and qualify their own raster converter.

JSON configuration remains compatible. New optional output paths are
`header_logo`, `favicon` and `gallery_raster_adapter`. Missing or empty strings
retain the existing text brand and SVG actions. Direct public `SiteConfig`
struct literals must add these three string fields; use empty strings to retain
prior behavior. This source compatibility change advances the version from
0.3.0 to 0.4.0. The supported toolchain remains MoonBit
`0.10.17+093cb8f9c`.

See [default presentation](../presentation.md) for the public styling and theme
contract. Existing tutorial, editor/Formatter and version-one extension
contracts remain covered by the independent public consumers.

## Install

Pin the real library in a native consumer's `moon.mod`:

```moonbit
import {
  "moonrockz/telescope@0.4.0",
}
preferred_target = "native"
```

Run `moon update`, then import the required public packages in `moon.pkg`,
such as `moonrockz/telescope/host`. Download the native archive and its `.sha256`
companion for the supported platform:

| Platform | Archive | SHA-256 |
| --- | --- | --- |
| linux-x64 | [telescope-0.4.0-linux-x64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.4.0/telescope-0.4.0-linux-x64.tar.gz) | `6dda974d670141382122519745057d4120bec0a5b5ff3895646fb07b5393b14c` |
| macos-arm64 | [telescope-0.4.0-macos-arm64.tar.gz](https://github.com/moonrockz/telescope/releases/download/v0.4.0/telescope-0.4.0-macos-arm64.tar.gz) | `b2042899a1ea9f51dde1b3c168211ad3c59be8ad6fddbd19f8b311fb0a80d591` |

```sh
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.4.0/telescope-0.4.0-macos-arm64.tar.gz
curl --fail --location --remote-name https://github.com/moonrockz/telescope/releases/download/v0.4.0/telescope-0.4.0-macos-arm64.tar.gz.sha256
shasum -a 256 -c telescope-0.4.0-macos-arm64.tar.gz.sha256
tar -xzf telescope-0.4.0-macos-arm64.tar.gz
./telescope-0.4.0-macos-arm64/telescope --version
```

The last command prints `0.4.0`. The binaries embed shared CSS and browser assets
and need no checkout or compiler. Compiled consumer providers require the pinned
toolchain. Other native platforms are not qualified. Archives retain resolved
third-party license records.
