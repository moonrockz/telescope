Context

The pure gallery planner already receives source_text. Detail pages render exact escaped source, while index cards render only previews. The host supplies declared UTF-8 source and canonical SVG independently. Existing viewer islands own their state and the native CLI embeds the shared assets.

Goals and non-goals

Use the same renderer and controller for both contexts. Keep the manifest and public plan signature compatible. Consumers own source associations and domain syntax; Telescope never reconstructs syntax from SVG or executes a renderer.

Decisions

SRC-1. Shared source and workbench renderer

Extract detail source sections into a helper and render an implemented card workbench. Prefix index panel and file IDs with the validated entry ID; retain detail panel IDs for compatibility. Preserve source order and unavailable-source downloads. Add a labeled filename selector for multiple files only when scripted; retain selection in each mounted workbench and keep every file visible without scripts. Escaping includes carriage returns and URL delimiters to survive version-tree rewriting. Duplicating the renderer would allow detail and index behavior to drift.

TAB-1. Enhance each mounted workbench

Initialize all workbenches independently with tabs and roving arrow/Home/End keyboard handling. Hide panels only after setup and toggle hidden without replacing DOM nodes. Static pages show both sections and no inactive tabs. This retains viewer transforms and avoids a whole-site application.

CSS-1. Reuse public classes

Keep gallery-workbench, gallery-tabs, gallery-tab, gallery-panel, gallery-source and gallery-source-file hooks. Use text tabs with an active underline, card-scoped spacing and source-height limits; use existing palette and focus tokens. Wrap viewer toolbar actions inside narrow cards. Source scroll stays inside each card.

Risks and trade-offs

RiskMitigation
More index HTML for large sourcesReuse host text eligibility checks and declared inputs. Accept static duplication for offline and no-script reading.
Repeated source paths across cardsPer-entry file IDs and browser duplicate-ID assertions.
Hidden viewer loses stateRetain DOM identity and test repeated toggle, pan, theme changes, filtering and actions.

Migration plan

Prepare additive 0.5.0 library and matching CLI, then qualify packaged independent consumers. The coordinator owns the combined implementation/release-preparation PR. Owner approval must name the concrete merged SHA and version before publication. Actual publication and both-platform public install evidence precede downstream adoption and final archive. A rollback pins the prior published version.
